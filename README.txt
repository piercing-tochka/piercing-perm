# Пирсинг Точка — готовый сайт

В этой папке находятся собранные страницы главной, обеих студий и мастеров Алёны, Натальи, Юлии и Екатерины. Все страницы используют общие стили и скрипты. Оптимизированные фоновые изображения, логотипы и портреты находятся рядом с HTML; прозрачный портрет Екатерины сохранён в WebP с lossless сжатием.

Для публикации загрузите содержимое `dist` в корень сайта. Главная страница — `index.html`.
